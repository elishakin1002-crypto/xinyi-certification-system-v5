# 系统出问题了怎么办 —— 一页纸

**发给全体同事。建议打印一张贴在工位，或存到手机里。**
新系统上线头两周，出点状况是正常的。这页纸只说三件事：**什么时候找人、找谁、等的时候你该做什么。**

---

## 一、什么情况**立刻**报，不要自己扛

这四种，**停下来先报**，不要反复重试：

1. **打不开 / 一直转圈** —— 刷新一次还不行就报
2. **数字不对** —— 金额、回款、项目数和你知道的对不上
3. **东西不见了** —— 刚录的合同、客户、任务，刷新后没了
4. **看到了不该看到的** —— 比如你能看到别人的客户或金额

> **「数字不对」和「东西不见了」这两条最要紧。** 页面打不开大家都看得见，
> 而数字错了看起来一切正常 —— **只有你能发现**。哪怕只是"感觉不太对"也请说。

其他的（字歪了、颜色怪、手机上挤）**攒着周五一起说**，不用当场报。

## 三、报的时候说清这四样（30 秒的事，能省一小时）

```
1. 你当时在哪个页面       例：合同管理
2. 你点了什么             例：点了「确认到账」
3. 你看到什么             例：转圈转了半分钟，然后白屏
4. 几点发生的             例：今天 10:25 左右
```

**再截一张图**（手机拍屏幕也行）。有截图和时间，我们能直接查到那一刻的记录；
没有的话，往往要来回问好几轮。

---

## 四、等我们处理的时候，你做这三件事

1. **不要反复点** —— 重复提交可能变成两条一样的记录，事后清理更麻烦
2. **不要换个浏览器再录一遍** —— 同一件事录两次，对不上账
3. **把手上的事记在纸上** —— 好了之后一次补进去

**你已经录进去的东西不会因为报故障而消失。** 不确定有没有存上，就问，别重录。

---

## 五、万一要「回退版本」

如果问题严重，我们会把系统**退回到上一个正常版本**（几分钟）。这时候：

- 系统会**短暂打不开**（通常 2–5 分钟）
- **退回时间点之后录入的内容，可能需要重录** ——
  我们会明确告诉你"是几点之后的"，你只补那一段

我们会在群里发：**「现在开始回退，大家先别操作」** 和 **「好了，可以用了」**。
看到第一条就停手，看到第二条再继续。

## 六、这几件事**不用报**，自己就能解决

| 情况 | 你自己做 |
|---|---|
| 页面显示怪怪的 | 按一下 `Ctrl + F5`（Mac 是 `Cmd + Shift + R`）强制刷新 |
| 忘记密码 / 登不进去 | 找系统管理员重置，不用等技术 |
| 第一次登录让改密码 | 正常的，改一个你自己记得住的 |
| 某个菜单看不见 | 多半是权限就这么设的。确实该看得到，再报 |
