## 账号

六个角色各一个，用户名 `ui-admin` / `ui-sys-admin` / `ui-manager` /
`ui-sales` / `ui-consultant` / `ui-finance`。

**密码不在这份文件里，也不许写进任何报告。**
用 `await loginAs(ctx, 'SALES')`（`scripts/ui-agent.mjs`），
它自己去 `.runtime/ui-accounts.json` 读，调用方拿不到那个字符串。

账号不存在或登不上时：`node scripts/ui-accounts.mjs --reset`。
