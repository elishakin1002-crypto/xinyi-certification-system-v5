# 角色与视角模型（多岗兼任版）

## 目标

本系统面向小型咨询公司常见的“身兼数职”场景，角色系统必须同时满足：

- 一个人可以拥有多个角色（roles）
- 任意时刻只能处于一个工作视角（activeRole），用于聚焦默认视图与默认筛选
- 权限（permissions）与视角分离：能不能访问由 roles 决定；默认看什么由 activeRole 决定

## 核心概念

### 用户档案（UserProfile）

- `id`：用户唯一标识（演示版可固定为 `U-LOCAL`）
- `name`：显示名称
- `roles`：该用户拥有的角色集合（多选）
- `activeRole`：当前工作视角（单选，必须属于 roles）

### 角色（RoleID）

- `ADMIN`：老板
- `MANAGER`：交付负责人
- `CONSULTANT`：咨询师
- `FINANCE`：财务

### 权限（PermissionCode）

系统用一组可枚举的权限码控制模块入口与路由访问，最小可行集合如下：

- `NAV_CRM`：客户经营（线索/客户/合同）
- `NAV_DELIVERY`：项目交付（项目管理）
- `NAV_FINANCE`：财务回款（回款概览/顾问结算）
- `NAV_AUDIT`：审核与整改（不符合项管理）
- `NAV_KNOWLEDGE`：知识中心
- `NAV_STRATEGY`：战略管理
- `NAV_AI_CENTER`：AI 配置中心

| MANAGER | ✅ | ✅ | ❌ | ✅ | ✅ | ✅ | ✅ |
| CONSULTANT | ✅ | ✅ | ❌ | ✅ | ✅ | ❌ | ✅ |

- 视角不改变权限：用户拥有多个角色时，其有效权限为 roles 对应权限的并集。

## 各角色默认视角（默认筛选/默认卡片）

### ADMIN（老板）
- 默认关注：逾期风险、关键项目停滞、回款异常、机会与利润
- 默认筛选：项目按风险/逾期优先排序

### MANAGER（交付负责人）
- 默认关注：项目交付推进、任务即将到期、资源负载
- 默认筛选：仅显示进行中项目，按截止日期升序

### CONSULTANT（咨询师）
- 默认关注：我的任务、我负责的项目、近期到期证书/节点
- 默认筛选：默认仅看“与我相关”（负责人/任务 owner 命中）的项目与提醒

### FINANCE（财务）
- 默认关注：应收款到期、逾期回款、结算草稿
- 默认筛选：回款按到期日升序，逾期置顶

## 演示版约束

- 不做真实登录与鉴权，使用 LocalStorage 模拟单用户档案。
- 路由守卫只做前端拦截，用于防止误入敏感模块（如财务）。
