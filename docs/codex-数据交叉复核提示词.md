## 怎么用浏览器

```js
import { open, loginAs, goto, cards, text, rows, clickText, snap, close } from './scripts/ui-agent.mjs';
const ctx = await open();
await loginAs(ctx, 'ADMIN');
await goto(ctx, '/projects');
console.log(await cards(ctx));      // [{名字, 数字}]
await snap(ctx, '项目管理-全公司'); // 截图存证
```
