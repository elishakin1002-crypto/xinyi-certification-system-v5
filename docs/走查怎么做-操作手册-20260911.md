# 产品负责人走查 · 具体怎么做

- **日期**：2026-09-11
- **在哪做**：**本地 `http://localhost:3000`**（不是生产）
- **总时长**：约 95 分钟，可以分两次
- **回答的问题**：「是对每个角色的 ID 都按流程走一遍吗？」

---

## 先回答：不是

**按业务链路走，不按角色走。角色切换是链路的一部分。**

### 为什么

真实的一单要经过好几个人的手：

```
录线索 ──→ 转客户 ──→ 签合同 ──→ 建项目 ──→ 指派 ──→ 干活记日志 ──→ 确认回款
  总经理      总经理      总经理      总经理     总助       顾问          财务
         ↑           ↑           ↑          ↑         ↑            ↑
       交接点1     交接点2     交接点3    交接点4   交接点5      交接点6
```

**bug 最集中的是这几个交接点，不是某个角色页面内部。**

比如「总助指派给邦煜 → 邦煜的『我的任务』里出不出现」——
这条只有**连着走**才测得出来。六个角色各测各的，永远发现不了。

各角色分别走一遍全流程 = 6 倍工作量，而且**恰好漏掉最容易坏的地方**。

## ⚠️ 一个会让整轮走查白做的陷阱

系统里有「切换视角」功能。**不要用它做走查。**

代码里写得很明白：

> 带「仅看板」的只换工作台，**不改权限**。权限始终按账号本身的角色判定。

**用切换视角走查，权限问题一个都测不出来。**
必须**真的退出登录、重新用另一个账号登入**。

退出在右上角头像 → 退出登录。

## 遇到问题怎么记

**四样缺一不可**：

```
① 页面 + 演的哪个角色 + 屏幕宽度      ← 很多问题只在特定组合出现
② 我做了什么
③ 结果是什么（截图最好）
④ 我以为会怎样
```

分级：

| 级别 | 意思 | 我怎么处理 |
|---|---|---|
| **阻断** | 干不了活 | 立刻修 |
| **严重** | 能绕但难受，或**数字不对** | 上线前修 |
| **一般** | 界面别扭、文案看不懂 | 测试期后统一改 |
| **建议** | 想要的新功能 | **记录，不做** |

最后一条是纪律：真实业务一跑，需求像雪片一样来，全接就永远上不了线。

## 卡住了怎么办

| 情况 | 办法 |
|---|---|
| 数据搞乱了 | `npm run walkthrough:reset` 一键还原 |
| 想看造了多少 | `npm run walkthrough:status` |
| 密码忘了 | `.runtime/走查账号密码.json` |
| **连错 5 次锁了** | `npm run walkthrough:accounts -- --fix` 自己解开，不用等 15 分钟 |
| **还原之后登不进去了** | 同上一条命令。（这个坑 9/11 已经修掉：还原不再碰账号表） |
| 页面白了/报错 | **截图 + 告诉我在哪一步** |
