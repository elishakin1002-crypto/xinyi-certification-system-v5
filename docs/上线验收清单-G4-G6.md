# 上线验收清单 —— G4（真人走主线）/ G6（财务核对数字）

这两条是**我做不了**的：G4 要的是"这就是我平时干的活"，只有干这个活的人能判断；
G6 要的是"和我手上的账对得上"，只有财务能判断。机器跑绿不等于这两件事成立。

**预计耗时：G4 每条主线 20–30 分钟，六条共约 2.5 小时（可分两天）；G6 约 1 小时。**

---

## G4 六条业务主线 —— 找对应岗位的人各走一遍

### 走的时候每步做「三看」

| 看什么 | 具体做 | 为什么 |
|---|---|---|
| **看下游** | 这一步做完，该出现的地方出现了吗 | 建了合同，客户页/项目页/财务页看得到吗 |
| **看刷新** | 按 F5，东西还在吗 | 「删了刷新又回来」这类问题只有刷新才暴露 |
| **看换人** | 换个角色登录，看得到吗、数字一样吗 | 权限和口径有没有对上 |

> **走的人不用懂技术。** 唯一的要求是：**遇到"咦？"就停下来记一笔**，
> 哪怕说不清哪里怪。说不清的那种感觉，往往正是口径不对。

### 主线 1 ｜ 销售：线索 → 转客户 → 建合同 → 录回款计划

**谁走：** 一线销售（建议找最常录合同的那位）

- [ ] 新建一条线索，填真实字段（不要填"测试"）
- [ ] 线索详情里点「转为客户」
- [ ] **看下游**：客户管理里出现了这家吗？名字、联系人对吗？
- [ ] 给这家客户建一份合同（金额用真实量级，比如 3 万）
- [ ] 合同里加两个回款节点（首付款 / 尾款），填到期日
- [ ] **看下游**：财务页的应收里，这两笔在吗？金额和日期对吗？
- [ ] **看刷新**：F5 之后都还在吗？

### 主线 2 ｜ 总助：合同立项 → 指定负责人和交期 → 看谁手上重

- [ ] 看一眼"谁手上的活最重" —— **和你心里的判断一致吗？**

### 主线 3 ｜ 顾问：接任务 → 改状态 → 记工作日志

**谁走：** 一线咨询顾问

- [ ] 用顾问账号登录，在「我的任务」里找到刚派的活
- [ ] 把一个任务改成「进行中」

### 主线 4 ｜ 财务：确认到账 → 看逾期 → 顾问结算 → 导出

**谁走：** 财务（这条最重要，和 G6 连着）

**谁走：** 系统管理员

- [ ] 建一个新员工账号，给临时密码

## G6 财务核对 —— 这些数字要和你手上的账对得上

**给财务的说明：下面每个数字都写了"它到底数的是什么"。
请对照你自己的账核一遍，对不上的写在右边 —— 对不上不一定是系统错，
也可能是口径不同，但必须说清是哪一种。**

| 数字 | 在哪看 | **它数的是什么（口径）** | 你的账 | 对得上？ |
|---|---|---|---|---|
| **本月实收** | 财务页 | **实际到账日**落在本月的已收款。按银行到账那天归月 | | |
| 未记到账日的笔数 | 本月实收旁边 | 历史数据没有到账日，**不硬塞进任何一个月**，单独列出来 | | |
| **本月应收** | 财务页 | **约定到期日**落在本月的应收（不管收没收到） | | |
| **回款率（进度）** | 合同/工作台 | 已收 ÷ **合同总额**。看这单收了多少 | | |
| **催收率** | 财务页 | 已收 ÷ **已到期应收**。未到期的不进分母 | | |
| 回款计划缺口 | 合同页提示 | 合同总额 − 各期计划之和。**大于 0 = 有钱没拆进节点** | | |
| **逾期回款** | 财务页 | 过了到期日还没收到。**到期日当天不算逾期** | | |
| 未支付结算金额 | 结算页 | 含"待确认"的那部分，所以比草稿筛选的金额大 | | |
| **营收** | 工作台 | 已结项的**客户项目**金额汇总 | | |

### 重点解释两件事（这是这次专门改的）

**1. 「本月实收」和「本月应收」本来就应该对不上。**
一个按钱**到账**那天算，一个按**约定该收**那天算。八月到期、九月才收到的钱：
在**八月的应收**里，在**九月的实收**里。对不上的那部分，正是"该收没收到"。

> 改之前这两件事是混在一起的：卡片写着「本月已收」，算的却是"到期日在本月且已收到"——
> 拿它对银行流水永远对不上。

**2. 「回款率」有两个，答的是两个问题。**
- **进度**（已收 ÷ 合同总额）：昨天刚签的合同显示 0% 是正常的，钱还没到期
- **催收**（已收 ÷ 已到期）：这个跌下来，就一定是真的该收没收到

只看第一个会误判，所以两个都要有。
