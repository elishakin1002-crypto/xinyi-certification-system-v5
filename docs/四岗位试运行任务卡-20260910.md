# 四岗位试运行任务卡

每人使用自己的账号，从自己真实负责的一个在办项目开始。未发生的审核、收款、结项不在真实业务数据上模拟；完整流程演练放隔离测试环境。负责人和下一步任务先由业务方确认。

| 测试人 | 当天要完成的业务动作 | 核对结果 |
|---|---|---|
| 李智薇（总助） | 查看全公司项目和工作量；给一位顾问分派一项真实任务；跟进一次卡点；汇总进度 | 负责人是真人；顾问账号看得到任务；对方更新后总助能看到结果；敏感权限按授权生效 |
| 黄邦煜（体系认证） | 找到自己的体系项目及服务项；完成当前实际节点；记录现场问题和整改证据；整理一条可复用经验 | 客户、服务项、任务、问题和资料对应正确；下一步不包含已跳过任务；记录刷新后仍在 |
| 黄佳佳（食品认证） | 在真实 SC 项目中检查资料缺口、现场条件及整改事项；更新当前申请/审查节点；有真实到期日期时核对提醒 | 流程能表达食品认证业务；需要什么资料、谁来补、下一步做什么清楚；不自动创建多余项目 |
| 商春姿（食品包装） | 核对食包咨询、台账检验、设备校准对应的服务项；完成当前一项工作并填工时；关联证据或资料 | 多个服务项的任务不混淆；0.5 小时刷新后仍为 0.5；问题和交付资料能再次找到 |

共同核对：电脑完成一次保存，刷新确认；手机打开同一项目确认结果。新增日志和不符合项由两个人同时操作时核对双方记录；故意冲突的修改只在隔离测试案例中做。

出现“有内容尚未保存到服务器”时，先导出未保存内容。网络问题可重试；记录冲突交给管理员核对后重新加载。不要把页面上的本地变化当作服务器已保存成功。

每条反馈填写：姓名｜客户/项目编号｜时间｜操作步骤｜期望结果｜实际结果｜截图｜是否阻断业务｜复测结果。

收尾：每人说明“今天是否能完成真实工作、在哪一步停住、是否需要回到 Excel/微信补做”。账号能登录或页面能打开，不代表岗位全流程验收通过。
