## 每次发之前先让它同步

```bash
git log --oneline -10
```

上一轮报告里的七条已经全部修掉并提交。工作副本落后的话会重复报。

## 已定、不用再问的口径

- 没日期的提醒 → 「待安排」，不进「今天要做」
- 客户总数 → 建了档就算
- 项目管理四张卡 → 进行中项目 / 7 天内要交 / 有逾期任务的项目 / 待补信息
  （四张全部数项目）
- 今天到期 → 任务和回款都**不算**逾期
- 没填日期 → 不算逾期（没约定就没有迟到）
- 已跳过 → 算了结，不算未完成
- 已结项项目里的残留任务 → 不进「我今天的活」

## 关于 .env.local 的授权

允许 Codex 用 `dotenv` 加载 `.env.local` 连数据库、建和清理 UAT 账号，
照 `scripts/check-intel-fetch.mjs` 的写法。
禁止的是**打印/记录/贴出里面的值**，不是加载动作本身。

## 两种派活方式（2026-09-15 起）

### A. 我直接调（不用你转贴）

```bash
bash scripts/codex-run.sh docs/<提示词文件>.md "这一轮的补充说明"
```

- 实时过程：`tail -f .runtime/codex-logs/latest.log`
- 流水账：`docs/协作日志.md`（我和它各记一行，中文，你看这一个文件就够）

**能干什么**：代码走查、报告整理、数据对账、跑脚本、写文档 —— 所有不用点界面的活。

**干不了什么**：**碰不了浏览器**。无头模式下它的浏览器访问要人当场批准，
无人值守时没人批，会直接卡住（2026-09-15 实测，它自己诚实报了这个卡点）。

### B. 你在 Codex 桌面 App 里跑

需要点界面、看屏幕的活（357 条按钮、六角色工作流）走这条。
那边你在场，能批准它访问 localhost:3000。

### 浏览器验证由我做

今天所有修复的证据都是我在真浏览器里量出来的（登录、点按钮、
脚本量 375px 布局、查两处存储）—— 这一块不需要等谁批准，
也不必占用 Codex。
