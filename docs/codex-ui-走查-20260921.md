# Codex UI 走查报告（2026-09-21）

## 结论与口径

- 实际使用六个独立账号登录：ADMIN / SYS_ADMIN / MANAGER / SALES / CONSULTANT / FINANCE；没有用“切换视角”代替真实登录。
- 共确认 **85 个角色×页面**，每页实跑 **1280×900** 和 **375×812**，合计 **170 个尺寸单元**。
- 检查动作包括：页面实际打开、可见安全按钮实点、每个页面内搜索框输入无命中词并清空、统计卡/筛选/列表对账、铃铛角标与面板条目对账、横向溢出、桌面/手机操作差异、控制台错误。
- 没有点删除、停用、归档、确认到账、保存、提交等会改变业务数据的操作；没有创建测试数据。
- 共确认 **10 个可独立复现的问题模式**：数字/列表口径 2 个、卡片跳转或筛选失效 3 个、手机功能缺失 1 个、权限接口红字 2 个、排版 2 个。未发现整页白屏或页面级横向溢出。
- 严重度汇总：**拦上线 0；该修 9 个；小瑕疵 1 个**。

## ADMIN（总经理）

### 发现 A1：线索统计数字与对应列表不一致

页面 / 尺寸 / 角色：线索管理 / 1280×900、375×812 / ADMIN

现象：顶部显示“线索总数 456”“跟进中 455”“已转化 1”。实际点“全部”后表格有 455 条；点“新增”仍为 455 条；点“跟进中”只有 1 条明确标注“样例·不是真实数据”的演示行和空态，真实记录为 0；点“已转化”有 1 条真实记录。也就是“跟进中 455”实际对应的是 455 条“新增”，且“全部”没有包含那 1 条已转化记录。

复现：登录总经理 → 线索管理 → 记录顶部四个数字 → 依次点“全部 / 新增 / 跟进中 / 已转化”并数表格真实业务行。

严重度：该修

### 发现 A2：手机合同列表丢失桌面操作，点卡片也无反应

页面 / 尺寸 / 角色：合同管理 / 375×812 / ADMIN

现象：桌面合同行有“转项目”“归档合同”，手机合同卡两项都没有；点合同标题、客户名或卡片空白处都不会打开详情或操作菜单。手机端因此无法执行桌面可见的合同操作。

复现：合同管理 → 范围点“全公司” → 桌面可见“转项目 / 归档合同”；切到 375×812 → 点“咨询服务合同书”卡片，无跳转、无抽屉、无弹窗。

严重度：该修

### 发现 A3：手机合同范围控件被挤成竖排字

页面 / 尺寸 / 角色：合同管理 / 375×812 / ADMIN

现象：“范围 / 与我相关 / 全公司”被压成约 42px 宽的窄列，“与我相关”四个字逐字换行，“全公司”三字竖排；虽没有横向滚动条，但阅读和点击体验明显异常。

复现：手机尺寸进入合同管理，滚到四张统计卡下方的范围切换区。

严重度：小瑕疵

### 发现 A4：知识分类按钮同排尺寸严重不一致

页面 / 尺寸 / 角色：知识中心 / 1280×900 / ADMIN

现象：同一排分类按钮通常约 30px 高，“回款复盘补偿”被挤成约 61×66px 的竖向按钮，并把右侧搜索框挤到不齐的位置。

复现：桌面尺寸进入知识中心，查看分类按钮行最右侧。

严重度：该修
