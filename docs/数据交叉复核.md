## 阻断详情

- 症状：宿主机上确有 Node 进程监听 3000 和 3001，后端进程也与本机 5432 的 PostgreSQL 保持连接；但当前 Codex 命令沙箱对 `localhost` 连接全部失败。
- Playwright 证据：使用仓库指定的 `scripts/ui-agent.mjs` 启动真 Chromium 时，Chromium 因 macOS Mach 端口注册被拒绝而在打开页面前退出。
- 备选通道：Chrome 浏览器接管通道报请求头策略无法加载；系统级 Chrome/Safari 控制同样未被当前环境批准。
- 影响：无法通过真浏览器创建并登录六个账号，无法读取 73 个“角色 × 可访问页面”的渲染结果，也无法生成有效截图。
- 判断：这是本次执行权限/隔离层的环境问题，不是对业务数字的结论。
