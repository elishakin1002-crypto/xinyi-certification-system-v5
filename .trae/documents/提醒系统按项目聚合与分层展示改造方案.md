## 目标
- 解决同一家客户 / 同一项目出现多条相似提醒导致的信息噪音问题。
- 让老板视角下的提醒更聚焦在“哪几个项目/客户有问题”，而不是“具体有多少个任务逾期”。
- 不改变现有扫描规则（业务规则继续细粒度判断），通过**展示层“聚合 + 分层”**来提炼信息。

## 设计思路

1. **保持底层“原子提醒”不变**
- 现有规则（任务逾期、严重逾期、僵尸项目、证书到期、AI 风险等）继续照常生成 `Reminder`。
- 这些原子提醒主要用于：
  - 可追溯：需要时还能看到是哪一个任务触发。
  - AI 决策：以后如果要训练/分析也有细粒度数据。

2. **新增一层“聚合视图”（Derived View）**
- 在 `AppContext` 中基于 `visibleReminders` 计算一个派生结构，例如：

  ```ts
  interface AggregatedReminder {
    id: string;              // 聚合后的 id（如 PROJECT-${projectId}-SEVERE-DELAY）
    projectId: string;
    customerName?: string;
    projectName: string;
    severity: 'high' | 'medium' | 'low';
    mainScene: string;       // 主场景：如 “严重逾期预警” / “长期停滞” / “证书到期”等
    count: number;           // 该项目下被聚合的原子提醒数量
    latestDate: string;      // 最近一次提醒日期
    samples: Reminder[];     // 若干代表性原子提醒（比如前 3 条）
  }
  ```

- 聚合规则：
  - **按项目维度**聚合：所有 `linkType === 'project'` 且 `linkId === 某项目` 的提醒归为一组。
  - 严重程度：
    - 严重逾期（`AUTO-OVER-L2-*` / 标题含“严重逾期预警”） → `high`。
    - 一般逾期 / 僵尸项目 / 长期停滞 → `medium`。
    - 到期提醒 / 机会提醒 → `low`。
  - 主场景选择：按严重程度优先级，从该组内挑一条代表性提醒的标题 + 文案。

3. **前端展示分层**
- 在工作台提醒窗口中：
  - **老板视角（activeRole = BOSS/ADMIN）**：
    - 默认展示 **聚合后的卡片列表**（按 `severity` 降序、再按 `latestDate` 降序）。
    - 每张卡片类似：
      - 抬头：`严重项目预警` / `重要项目待推进`。
      - 副标题：`客户：XX公司 · 项目：YY`。
      - 重点文案：采用 `mainScene` 对应代表性文案。
      - 角标：`共 N 条风险 / 逾期任务`。
      - 点击卡片：跳转到对应项目详情；卡片内部可展开“查看具体任务预警列表”。
  - **执行视角（项目经理 / 咨询顾问）**：
    - 仍可选择“原子级列表”模式，便于逐项处理任务。
    - 或支持切换为“按项目聚合”查看整体风险分布。

4. **去重与可见性保持现状**
- 底层提醒仍通过 `upsertSystemReminder` 按场景去重（同一任务同一规则只生成一条）。
- 聚合视图不额外做去重，只对已有 `visibleReminders` 做分组，天然继承了角色/用户过滤规则（`forRole`/`forUserIds`）。

## 实现步骤（后续编码用）

1. **扩展严重级别判定工具**
- 在 `AppContext` 内新增一个小工具函数：

  ```ts
  const getReminderSeverity = (r: Reminder): 'high' | 'medium' | 'low' => { ... };
  ```

- 根据 `r.type`、`r.title` 或 `r.id` 前缀(`AUTO-OVER-L2`, `AUTO-STAGNANT`, `AUTO-EMPTY` 等) 来映射严重度。

2. **构建 `aggregatedReminders` Selector**
- 在 `AppContext` 里基于 `visibleReminders`：
  - 只拿 `linkType === 'project'` 的提醒。
  - 以 `projectId = r.linkId` 为 key 分组。
  - 对每一组：
    - 计算 `severity = max(getReminderSeverity(r))`。
    - `count = group.length`。
    - `latestDate = max(r.date)`。
    - `samples = group.slice(0, 3)`。
    - 从 `projects`/`contracts` 中补充 `projectName` / `customerName`。

3. **Dashboard 中增加“聚合视图”展示**
- 在工作台 `Dashboard.tsx` 中：
  - 从 `useApp()` 额外取出 `aggregatedReminders`。
  - 针对老板视角：优先展示 `aggregatedReminders` 列表，每个聚合卡片样式类似现在的卡片，但文案更概括：
    - 标题：根据 `severity` + `mainScene` 决定，如“严重逾期预警”“项目长期停滞”。
    - 内容：`该项目下共有 N 条风险/逾期任务，最近一次为 YYYY-MM-DD ...`。
    - 标签：客户名 + 项目名。
  - 卡片可增加“展开查看明细”按钮，在弹层或卡片下方列出 `samples` 对应的原子提醒，方便追溯。

4. **保留原子列表作为二级视图**
- 在提醒区域中预留一个切换控件：
  - `聚合视图` / `明细视图`（可在老板视角默认选中“聚合视图”）。
- 明细视图继续沿用现在的 `visibleReminders.map(...)` 渲染方式，不影响已有使用习惯。

5. **后续可选增强**
- 在 `AggregatedReminder` 中增加 `tags: string[]`：如“证书到期”“内部审核”“管理评审”，便于未来在提醒中心做搜索/筛选。
- 在“进入全量审计中心”页面，沿用同样聚合逻辑，但支持按照客户 / 项目 / 时间区间做过滤统计。
