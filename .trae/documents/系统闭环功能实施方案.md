# 系统闭环功能设计方案

## 核心目标
解决“项目完成后无后续动作”的痛点，构建“完成即开始”的自动化闭环：
1. **固化结果**：项目完成时自动生成不可篡改的履历。
2. **反哺客户**：项目数据自动回写到客户档案（状态、合作历史）。
3. **埋下提醒**：自动计算未来关键节点（如证书到期）并生成系统提醒。
4. **转化挖掘**：基于完成状态自动筛选“可转化池”客户。
5. **规则进化**：记录偏差数据（预留接口）。

## 详细实施计划

### 1. 状态模型升级（Projects & Types）
- **Types 更新**：确认 `Status.Completed` 已存在（无需新增）。
- **Project 结构**：确保 `Project` 包含 `completionRecord` 字段（需新增类型定义）。
    - 字段包括：`actualEndDate`（实际完成日）、`duration`（实际周期）、`passRate`（是否一次通过）、`taskCompletionRate`（任务完成率）。

### 2. 项目完成触发器（AppContext）
新增 `completeProject(projectId)` 方法，执行原子化闭环操作：
1.  **状态更新**：将项目状态置为 `Completed`，进度置为 100%。
2.  **生成结果记录**：
    - 计算实际周期（当前时间 - 创建时间）。
    - 统计任务数据（总数/已完成/延期数）。
    - 写入 `completionRecord`。
3.  **反哺客户数据**：
    - 查找关联客户。
    - **首次交付**：若客户状态为 `New/Potential`，自动改为 `Active`（合作中）；写入 `firstServiceDate`。
    - **续证/跟进**：更新 `lastServiceDate`，`serviceCount + 1`。
    - **证书数据**：如果是认证项目，尝试更新/新增客户的证书记录（`certificates`），写入 `expiryDate`（默认当前+3年，或从项目字段取）。
4.  **生成未来提醒**：
    - 基于证书到期日（或项目结束日+周期），生成 180/120/90 天倒计时的 `Reminder`。
    - 提醒类型为 `opportunity`（商机）或 `expire`（到期）。
    - 写入 `Reminder` 表。

### 3. 前端视图改造
#### A. 客户管理（Customers.tsx）
- **新增“可转化池”视图**：
    - 在顶部 Tabs 增加 `可转化池`（`Conversion Pool`）。
    - **筛选逻辑**：
        - 客户状态 = `Active`（合作中）。
        - 且 `certificates` 中有即将到期（<180天）的记录，或者 `lastServiceDate` 距今超过一定时间（如1年）。
    - **列表展示**：
        - 客户名、最近项目、**系统建议**（如“证书将在90天后到期，建议跟进”）。

#### B. 项目管理（Projects.tsx）
- **默认视图过滤**：
    - 进入页面默认 `filterStatus !== 'Completed'`（只看进行中）。
    - 增加“已完成”视图切换按钮。
- **完成操作入口**：
    - 在项目卡片/详情页增加“标记完成”按钮（需二次确认）。
    - 点击后调用 `completeProject`。
- **结果记录卡片**：
    - 在项目详情页底部新增 `ProjectCompletionCard`。
    - 展示：实际周期、完成时间、系统评级（如“优秀交付”）。

### 4. 涉及文件
1.  `types.ts`: 新增 `ProjectCompletionRecord` 接口，更新 `Project` 接口。
2.  `context/AppContext.tsx`: 实现 `completeProject` 核心逻辑（包含上述4步闭环）。
3.  `pages/Projects.tsx`: 增加完成按钮、结果卡片、列表过滤。
4.  `pages/Customers.tsx`: 增加“可转化池”视图及筛选逻辑。

## 验证逻辑
1.  **操作**：在项目列表点击“完成”一个交付项目。
2.  **验证项目**：项目从“进行中”消失，进入“已完成”；详情页出现“结果记录”。
3.  **验证客户**：对应客户状态变为“合作中”；“最近服务时间”更新。
4.  **验证提醒**：在首页或提醒中心看到“未来X月到期”的预埋提醒（需调整时间模拟或查看数据库）。
5.  **验证转化池**：如果设置该客户证书即将到期，客户应出现在“可转化池”列表中。
