# 信义认证系统 V5.0 - 系统分析报告

经过对代码库的全面分析，我已经掌握了该系统的架构、技术栈和核心业务逻辑。

## 1. 系统概览
这是一个**企业级管理系统（ERP/CRM）**，专为认证咨询行业设计，集成了**Google Gemini AI**能力。
- **核心理念**：全流程数字化（线索 -> 客户 -> 合同 -> 项目 -> 财务 -> 审计）。
- **运行模式**：**前后端分离**，但具备**混合容灾模式**（Hybrid Mode）。
  - 优先通过本地 Node.js 后端调用 AI（保护 API Key）。
  - 若后端不可用，自动降级为纯前端直连 Google API。

## 2. 技术架构
### 前端 (Client)
- **框架**：React 18 + Vite 5 + TypeScript。
- **UI 组件**：Tailwind CSS + Lucide React (图标) + Recharts (图表)。
- **路由**：React Router (Hash 模式)。
- **状态管理**：React Context (`AppContext.tsx`)。
- **数据持久化**：`LocalStorage` (封装在 `services/dataService.ts`，无真实数据库)。

### 后端 (Server)
- **核心文件**：`server/app.js`。
- **框架**：Express.js。
- **功能**：
  1. **AI 代理**：转发请求到 Google Gemini API，解决跨域和 Key 泄露问题。
  2. **文件处理**：使用 `multer` 处理内存上传。
- **API 路由**：
  - `/api/ai/generate`: 通用文本生成。
  - `/api/ai/chat`: 对话模式（支持 Tools）。

### AI 能力 (`aiService.ts`)
- **模型**：Gemini 3 Pro / Flash Preview。
- **特性**：
  - **智能路由**：自动检测后端健康状态，失败时自动切换到前端直连。
  - **业务场景**：战略分析 (SWOT/BCG)、文档分类、合同风险评估。

## 3. 核心业务模块
1.  **仪表盘 (Dashboard)**：全盘数据概览。
2.  **线索 (Leads)** & **客户 (Customers)**：CRM 销售漏斗管理。
3.  **合同 (Contracts)**：合同生命周期与回款管理。
4.  **项目 (Projects)**：任务分解、进度追踪、外包/自营管理。
5.  **财务 (Finance)**：收支结算。
6.  **审计 (Audit)** & **合规**：ISO 认证流程的节点管理。
7.  **AI 中心**：集中的 AI 交互入口。
8.  **战略 (Strategy)** & **知识库 (Knowledge)**：辅助决策支持。

## 4. 待确认事项 (Next Steps)
目前系统是一个**单机演示版**（数据存浏览器）。如果您需要进行开发，可能的方向包括：
1.  **对接真实后端**：将 DataService 改造为对接数据库（如 Supabase/MySQL）。
2.  **增强 AI 功能**：开发更多具体的 AI Agent（如自动写标书、自动审核合同）。
3.  **UI/UX 优化**：针对特定页面进行细节优化。
