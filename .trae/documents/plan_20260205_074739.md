# T-002 费用补录入口缺失修复方案

根据【立即执行｜硬补丁】指令，我将立即修复项目费用补录入口缺失的问题，打通项目完结的死锁。

## 1. 后端逻辑支持 (`context/AppContext.tsx`)

### 新增 `updateProjectCost` 方法
- **参数**：`projectId`, `amount`
- **逻辑**：
  - 校验 `amount > 0`。
  - 更新项目 `projectAmount = amount`。
  - **自动联动**：强制设置 `costStatus = '已确认'`。
  - 不允许手动传入 `costStatus`，状态流转必须由金额驱动。

## 2. 前端界面补全 (`pages/Projects.tsx`)

### 新增“费用信息区块” (Cost Section)
- **位置**：项目详情模态框，基本信息下方，任务列表上方。
- **展示内容**：
  - **项目金额**：`¥ xxx` (或 `未录入`)
  - **费用状态**：`待补全` (黄) / `已确认` (绿)
- **操作按钮**：
  - `✏️ 补录/编辑费用` (仅当 `status === Active` 时可见)。

### 费用编辑交互
- 点击按钮后，切换该区块为编辑态（或弹窗）。
- **输入框**：`Project Amount` (数字，必填)。
- **保存**：调用 `updateProjectCost`。
- **取消**：退出编辑态。

## 3. 验证闭环
- **场景**：打开一个 `costStatus='待补全'` 的项目 -> 点击“完成”被拒 -> 点击“补录费用” -> 输入金额保存 -> 状态变绿 -> 再次点击“完成” -> 成功。
